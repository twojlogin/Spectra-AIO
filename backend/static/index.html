Sieć / Proxy

Sprawdź czy Tor/VPN/proxy działa i jakie IP widzi świat. Bez działającego proxy moduły sieciowe będą zwracać błąd.

Ładowanie...

Opcje (konfiguracja .env)

Tor (domyślnie): SPECTRA_PROXY_MODE=tor, SPECTRA_TOR_PROXY=socks5h://127.0.0.1:9050

Tor Browser: zwykle port 9150.

Custom proxy / VPN: SPECTRA_PROXY_MODE=custom + SPECTRA_PROXY_URL=socks5h://host:port

Bez proxy (mniej prywatne): SPECTRA_PROXY_MODE=direct

Alternatywy: Proton VPN, Cloudflare WARP, lub dowolny lokalny SOCKS/HTTP proxy. Po zmianie .env zrestartuj backend.

Tor download: https://www.torproject.org/download/
